# Music Library Application

A full-stack Music Library Management System built with Spring Boot, PostgreSQL, JWT Authentication, Vue 3, Pinia and Vite.

## Features

### Authentication

* User Registration
* User Login
* JWT Authentication
* Role-Based Authorization
* Protected Routes

### Albums

* Create Album
* View Albums
* Edit Album
* Delete Album
* Album Cover Images

### Songs

* Create Song
* View Songs
* Edit Song
* Delete Song
* Assign Songs to Albums

### Frontend

* Vue 3 Composition API
* Pinia State Management
* Vue Router
* Axios API Integration
* Responsive Modern UI
* Reusable Components

### Backend

* Spring Boot
* Spring Security
* JWT
* PostgreSQL
* Flyway Migrations
* DTO Pattern
* Service Layer
* Repository Layer
* Global Exception Handling

## Technologies

### Backend

* Java 21
* Spring Boot
* Spring Security
* PostgreSQL
* Flyway
* Lombok

### Frontend

* Vue 3
* Vite
* Pinia
* Vue Router
* Axios

## Running the Backend

1. Open the backend folder.
2. Configure PostgreSQL.
3. Run Flyway migrations.
4. Start Spring Boot.

## Running the Frontend

1. Open the music-library-frontend folder.
2. Install dependencies:

npm install

3. Run:

npm run dev

4. Open:

http://localhost:5173
